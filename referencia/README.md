# Enunciado oficial del curso

La fuente primaria del proyecto es el documento de cinco páginas denominado **«Segundo Proyecto — Sistema de Gestión de Estudios Médicos Distribuido»**, del curso Bases de Datos II, TEC San Carlos, II semestre 2026.

**No se incluye el archivo original del profesor en este repositorio público.** Los integrantes deben consultarlo en Moodle o solicitar la copia por los canales internos del equipo.

La transcripción sintética y trazabilidad por sección/página se encuentran en [`../docs/01_REQUISITOS.md`](../docs/01_REQUISITOS.md). Ante discrepancia, prevalece el enunciado del curso.
